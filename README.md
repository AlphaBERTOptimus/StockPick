# 选股智能体 (Stock Picker Agent)

🤖 AI驱动的专业选股助手，支持中英文对话筛选股票

## ✨ 特性

- 🗣️ **双语对话**：支持中英文自然语言交互
- 📊 **全面分析**：35+基本面指标 + 25+技术指标
- 🎯 **投资策略**：长期投资、波段交易、日内交易
- 🔍 **智能筛选**：AI理解复杂筛选条件
- 📱 **响应式设计**：适配桌面和移动端

## 🚀 快速开始

\`\`\`bash
# 克隆项目
git clone https://github.com/AlphaBERTOptimus/stock-picker-agent.git
cd stock-picker-agent
